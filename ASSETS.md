# ASSETS.md — asset and font log

Policy (AGENTS.md §8, `docs/09-design-handoff.md` §11): **original work only.** Every asset in the repository has a row below with author, date, source file and license. An asset without a row fails review.

- Never commit, trace or export Apple assets, icons, wallpapers or fonts. Screenshots of other products are for private study and are never committed.
- Fonts need an open license (OFL-1.1 or Apache-2.0). Keep the license text next to the font file.
- A third-party asset needs a license compatible with D-016 and an entry on the in-app licenses page (M4.6).
- Placeholder art that an agent generates before the owner's Figma exports arrive is original, procedural, and marked `placeholder` so it gets replaced in M3.10.
